# Math Notes

A Word-style page for writing maths, hosted on GitHub Pages.

- **Alt+=** (or the Equation button) inserts an equation box. Type like Word's equation editor: `/` makes a fraction, `^` a power, `_` a subscript, `sqrt`, `pi`, `\alpha`, etc.
- Variables are remembered top to bottom. Type `x=y/z` and a grey suggestion `= 10/2 = 5` appears; press **Tab** to fill it in. The last number in `x=y/z=10/2=5` becomes the value of `x`.
- Untick **Equation → Show working step** to go straight to the answer (`= 5`).
- An equation with exactly one unknown (e.g. `10=2b+x`) is solved for it.
- Decimal places per variable: the Variables pane (View → Variables) or Equation → Increase/Decrease Decimal. The rounded value is what gets used in later equations.
- Copy (Ctrl+C) and paste into Word: equations arrive as real Word equations (MathML).
- Autosaves in the browser; File → Save a copy / Open for `.mathnotes` files.

To publish: repo Settings → Pages → Deploy from a branch → pick this branch, folder `/ (root)`.
