# Math Notes

An equations-only notebook in a Word-style window, hosted on GitHub Pages.

- Every line is an equation. **Enter** starts the next one; just type: `/` makes a fraction, `^` a power, `_` a subscript, `sqrt`, `pi`, `\alpha`, etc.
- Like Word, a space or an operator (`=`, `+`, `-`, …) typed in a subscript or power takes you back to the main line: `C_M=C_L` stays `C_M = C_L`, and `=` also leaves a fraction (`a/b=` gives a/b =). Use brackets to keep operators in a power: `e^(x+1)`.
- **Ctrl+Enter** (or Home → New section) adds a section: a line with a heading under it. Enter after the heading goes straight to an equation.
- **Alt+Enter** (or Home → New sub-label) adds a sub-label, one level under a label. A heading started on an empty line replaces that line.
- **Ctrl+Shift+Enter** (or Home → New label) adds a label: a smaller subheading for one equation or a group of equations. Ctrl+C on a label, or right-click → Copy labelled part, copies just that group.
- **Matrices** of any size: Home → New matrix… (or Symbols → Matrix → Custom size…). Inside a matrix, Enter adds a row; Home → Matrix (or right-click) adds/removes rows and columns.
- **Backspace** on an empty line deletes it; Home → Delete line deletes the current line.
- Variables are remembered top to bottom. Type `x=y/z` and a grey `= 10/2 = 5` appears; **Tab** fills it in. Filled-in numbers stay live: changing decimal places or an earlier value updates them on the page.
- **Units** follow the maths: variables keep their units (`m = 1200 kg`, pasted unit columns, universal constants), multiplying/dividing/powers combine them, and the answer is shown with the result (`p = mv = 1200·25 = 30000 kg·m/s`). Units are only converted when you pick one in the Variables pane (equations don't mix mm and m for you); adding things with different units shows no unit; degrees/radians count as dimensionless when adding. Type a unit after an answer to set it yourself.
- End a line with `=` when some variables are still unknown and it fills in the known ones, works out everything it can and leaves the unknowns: `c̄ = 2/3·c_r·(1+λ+λ²)/(1+λ) =` gives `= 0.8819 c_r`. Accented letters (c̄, x̂, v⃗…) are variables of their own; c̄ is the same as `c_bar` from a pasted table.
- If an equation mixes scales of the same kind of unit (mm with m, kPa with Pa…), values are converted to base SI units before calculating.
- An unknown that looks like a known variable (typed `a` where the definition used `α`, …) is flagged next to the suggestion: "isn't defined. Did you mean …?". `dε/dα` and `∂ε/∂α` are the same quantity.
- Equations never wrap: the page grows sideways to fit the longest line.
- Untick **Show working step** to go straight to the answer (`= 5`).
- An equation with exactly one unknown (e.g. `10=2b+x`) is solved for it.
- **Paste variables** (Home, or right-click a line): paste a table from Excel, Word or a web page (a symbol column, a value column and optionally a units column, in any order, header row optional, extra columns like descriptions ignored) or a list like `m = 5 kg` / `v0: 3.2`, one per line; symbols like `CL`, `ρ`, `v₀`, `AR_wing`, `C_(l_(α_Wing))` and `(∂ε)/(∂α)` (Word's equation text) and values like `1,200` or `2.1×10⁻³` are understood; Excel-style labels with the unit in brackets (`Temp (K)`, `S wing (m^2)`, `Sting Height h (m)`) are read too, whole words like `Temp` become multi-letter variables you can type in equations, and rows that are products of symbols (`Q·S·c_bar`) come in as an equation line; pasted variables go into a **Variables** section at the top (created if needed), and pasting a table again updates values that changed instead of repeating them. Pasting such a list straight into an equation (Ctrl+V) does the same. Units are kept on the page but ignored in the maths.
- **Universal constants** (g, G, c, k_B, N_A, ε₀, μ₀, mₑ, mₚ, qₑ) are known in every project, so `F=mg` fills in straight away. Writing `g=10` overrides it from that line down; ✕ in the Variables pane stops using one in this project; Edit changes the list for all projects.
- **Units in the Variables pane**: each variable has a Unit box: type your own or pick from the list (units that fit the variable's equations first, then units in the document, then common SI units). Units are kept as you type them (`s^-1` shows as s⁻¹). Picking a compatible unit **converts**: `c_root = 125 mm` → m rewrites the line as `0.125 m`, a calculated answer is shown in the new unit, and later lines use the converted value. Incompatible units just relabel (with a note).
- Decimal places per variable: the Variables pane dropdowns or the Increase/Decrease Decimal buttons.
- **Symbols panel** (left of the page): structures (fractions, roots, integrals, matrices…), Greek letters, calculus, arrows, sets and geometry symbols. Click to insert. View → Symbols shows/hides it.
- Copying for Word: **right-click any line → Copy section**, or click a section heading and press **Ctrl+C**, to copy that heading and its equations. Ctrl+C in an equation copies that equation; Home → Copy all copies everything. Equations paste into Word as real Word equations.
- **Projects** (File menu or folder button): create, name, rename, switch and delete separate projects; each saves automatically in the browser. **Ctrl+S** saves the project to a `.mathnotes` file: the first time you pick where, after that it overwrites the same file (Chrome/Edge; other browsers download a new copy each time). File → Save as… picks a new file; opening a project's file again updates that project instead of making a copy.

To publish: repo Settings → Pages → Deploy from a branch → pick this branch, folder `/ (root)`.
